## nano

* `(Ctrl + o )` Salvar arquivo

se você deseja renomear o arquivo, o nano te dará esta opção ao executar esse comando, caso não queira, pode deixar como esta.

* `(ENTER)` para confirmar título
* `(Crtl + x)` Sair

caso queira descartar alterações e sair, poderá prosseguir com o comando acima, o nano perguntará se deseja salvar. pressione `N` para não salvar.

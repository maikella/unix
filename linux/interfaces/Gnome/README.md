## listar extensões
```
gnome-extensions list
```
## extensão software (não oficial)
```
flatpak install flathub com.mattjakeman.ExtensionManager

flatpak run com.mattjakeman.ExtensionManager

pesquisar por: no overview at start-up by fthx
```
## remover
```
gnome-extensions uninstall no-overview@fthx
```
## desativar e ativar
```
gnome-extensions disable no-overview@fthx

gnome-extensions enable no-overview@fthx
```

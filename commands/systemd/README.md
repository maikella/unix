## Usando arquivos de unidade systemd para personalizar e otimizar seu sistema
Modifcando os arquivos de unidade do `systemd`, é possível expandir para diferentes tipos de configuração, você consegue personalizar melhor seu sistema além da configuração padrão. Você também consegue examinar o desempenho de inicialização do sistema e otimizar o `systemd` para reduzir o tempo de inicialização.

## Systemd
Systemd é o sistema subjacente (de baixo, funciona por baixo) que gerencia serviços, processos e recursos.
## Systemctl
Systemctl é uma ferramenta de linha de comando usada para interagir e controlar serviços e componentes do `Systemd`.

### Como funcionam
Systemd é um gerenciador de sistemas e serviços para sistemas Linux. Ele é responsável por inicializar o sistema, gerenciar os serviços do sistema e controlar o processo de desligamento. Systemctl é uma ferramenta de linha de comando que permite interagir com o Systemd.
